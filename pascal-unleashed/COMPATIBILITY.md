# 兼容性

| 类别 | 状态 |
| --- | --- |
| Windows x64 + Tesla P40，计算能力 6.1 | 本机 GPU 验收平台 |
| 其他 NVIDIA 6.1 | 代码可探测，设备验收待补 |
| 其他 CUDA 设备 | 驱动可枚举，自动按兼容性采用原生或报告不可用 |
| Microsoft .NET Framework 4.x | 面板与安装器依赖 |
| PyTorch CUDA Windows | 显式 `matmul`、推理 `linear`，按进程加载 |
| ComfyUI | 已有 FP32 工作流可使用发布 DLL 的去噪线性层接入脚本 |
| CUDA/C/C++ | 显存指针、流、行列布局、转置、批式调用 |
| NumPy | 可选 Python 主机接口，执行时复制到 CUDA |

## 已知限制

- v1.0 加速矩阵乘法。训练、卷积、逐元素指令等由原应用处理。
- 极小、特殊类型或超出加速范围的矩阵走原生，输入存在 NaN/Inf 且被加速编码发现时回退。精度容忍度为正时采用原生。
- 高精度档的同列异常值检查是启发式保护。用户数据仍需要对照原生验证，严重抵消无法用固定百分比保证。
- SDK 为同步调用。同一上下文串行，与其他 CUDA 流的同步仍由调用方管理。
- 透明接入面向显式开启加速的 Python 进程。可执行文件若需要加速，需要通过 SDK 调用加速层。进程权限、CUDA 路径和配置由面板显示或报错。
- CUDA 12 cuBLAS、模型和驱动由应用环境提供。多型号 GPU、系统休眠恢复、GPU 在运行中更换和 GPGPU 多机路径尚未验收。
