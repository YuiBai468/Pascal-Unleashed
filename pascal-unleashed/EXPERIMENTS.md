# 研究经过与踩过的坑

1. 从高低位拆分开始。两轮密集乘法可以重构主项和交叉项，剩余的余数乘积会决定数值精度。早期 CPU 实验发现改变基数和拆 K 分块能降低异常分布的误差，严重抵消仍然很差。
2. 对比 AR2、双轮以及基于正交平面的编码。平面投影让一轮 DP4A GEMM 也能计算一个近似乘积。扫描法向量、查表、编码尺度和直线坐标比例后，吞吐与误差落在可复测的不同折中点。
3. 查表精度提高时，物理 K 和打包开销也会上升。把短矩阵的结果直接外推到大矩阵、把核内吞吐写成端到端吞吐、或省略转置与恢复步骤，都会高估速度。历史表按实际执行路径保留完整计时样本。
4. 双轮精度方向加入稀疏补偿。较激进的裁剪阈值在普通正态矩阵上可以降低误差，增加的尾项会消耗显存带宽。尾项分包与 FP16 部分和缓冲帮助守住 18 T/s 左右。
5. 矩阵合成实验与生成网络给出不同排序。四个真实应用样本里，均衡档的图像最接近 FP32。把同列放大 32 倍的压力测试进一步说明高精度档的输入分布风险。公开结果包含失败路径。
6. 封装时将系统 CUDA 依赖动态加载，GPU 内核保持既有实现。已验证的推理适配移入进程级挂接。原生回退、输入检查和缓存版本约束由发布运行时处理。

复现历史性能时应使用原始尺寸、随机种子、编码参数和计时方式。封装后的数据请使用发布验收报告与随包的测试结果。
